
# 📚 Dove Studiamo?

Dove Studiamo? è un’app mobile sviluppata in Flutter pensata per studenti e universitari. Permette di trovare luoghi adatti allo studio tramite una mappa interattiva, applicare filtri per Wi-Fi, prese e silenzio, salvare i preferiti e scoprire nuovi spazi. L’obiettivo è rendere lo studio fuori casa più semplice, organizzato e produttivo.

## 🚀 Funzionalità

- 🗺️ Mappa interattiva dei luoghi di studio
- 🔎 Ricerca e filtri
- ❤️ Luoghi preferiti
- 📶 Filtro Wi-Fi
- 🔌 Disponibilità prese elettriche
- 🔇 Livello di silenzio
- 📍 Apertura del luogo su Maps
- 👤 Profilo utente

## 🛠️ Tecnologie

- Flutter
- Dart
- Firebase
- Google Maps

## 🎯 Obiettivo

L'obiettivo di Dove Studiamo? è creare una piattaforma collaborativa
che permetta agli studenti di trovare rapidamente il luogo più adatto
alle proprie esigenze di studio.
